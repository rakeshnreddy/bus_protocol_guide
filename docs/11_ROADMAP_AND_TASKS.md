# Roadmap and Task Breakdown

## Goal

Provide an execution-oriented breakdown that can be used directly by a coding agent or by manual implementation planning.

## Milestone 1 – App Skeleton
Tasks:
- Initialize project
- Add routing
- Add app shell
- Add markdown rendering
- Create docs/content folders
- Add starter theme and layout

## Milestone 2 – Content Infrastructure
Tasks:
- Define TypeScript schemas
- Add sample lesson files
- Add sample glossary data
- Add sample visual JSON files
- Add content loading helpers

## Milestone 3 – Foundational Visuals
Tasks:
- Build waveform component
- Build timeline component
- Build signal explorer
- Add demo datasets
- Verify responsiveness and readability

## Milestone 4 – Foundations Content
Tasks:
- Write foundational lessons
- Attach visuals
- Add self-check content
- Seed glossary and acronym expansion

## Milestone 5 – AHB Track
Tasks:
- Create AHB lesson files
- Build AHB-specific waveform datasets
- Add AHB review pages
- Add AHB verification and checklist content

## Milestone 6 – AXI Track
Tasks:
- Create AXI lesson files
- Build AXI-specific datasets
- Add AXI review pages
- Add AXI verification and checklist content

## Milestone 7 – Product Polish
Tasks:
- Improve navigation
- Add search
- Add glossary drill-down behavior
- Add revision routes
- Improve styling consistency
- Validate mobile experience

## Progress Rules

- Keep content and rendering separate.
- Prefer typed data over hardcoded page logic.
- Finish one vertical slice fully before expanding sideways.
- Verify usability after each milestone.
- Do not add backend complexity in Phase 1.

## Definition of “Ready for Coding Prompts”

The planning phase is complete when:
- architecture is fixed
- curriculum map is fixed
- content model is fixed
- visual components are defined
- implementation milestones are ordered

At that point, coding prompts can be written with far less ambiguity and much better execution quality.
